名の由来は「塩焼く」とも「潮湧く」とも言う

瀬戸大橋が通過する5つの島（塩飽諸島、すべて香川県坂出市）のうち、上陸できるのは3島
* 与島（よしま）　自家用車 または 路線バス 唯一、車で自由に降りられる塩飽七島の1島
* 岩黒島（いわくろじま）　路線バス（橋上のバス停からエレベーターで降下）
* 櫃石島（ひついしじま） 岡山に一番近い有人島 路線バスあり、塩飽七島の1島
* 羽佐島（わせしま）・三つ子島（みつごじま）は上陸不可・橋脚が通るのみの無人島

本島（ほんじま） - 児島観光港（岡山） 塩飽水軍の本拠地。古い町並みが残る

* 塩飽七島のうち（牛島 - 本島・広島 - 手島・小手島）へは、丸亀港からフェリーが運航
* 塩飽七島のうち（高見島）へは、多度津港 - 高見島（たどつ汽船）
