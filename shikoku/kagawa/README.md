古事記に見る神代の呼称は、伊予之二名島の顔（四国が持つ4の顔）の一つ「飯依比古（いいよりひこ）」

古くから稲作や穀物栽培（麦など）が盛んだった豊かな農業地帯で、現代でも「讃岐うどん」、瀬戸内海の「塩」・出汁（だし）に欠かせない「伊吹いりこ」などの豊かな食文化が受け継がれる

四国巡礼においては、究極の安らぎを与える「涅槃（ねはん）の道場」と呼ばれる遍路の締めくくりの場（県内には第66〜88番札所の23ヶ寺がある）

* 徳島との県境「讃岐山脈」周辺には、空海が水を治めて讃岐に豊かな食を与えたと伝わる「満濃池」、空海の祖先である佐伯氏の氏寺（うじでら）が建立したと考えられている白鳳時代の寺院跡「仲村廃寺」がある

平安時代初期には真言密教を興すことになる弘法大師空海が讃岐国那珂郡に生まれた

石器時代、鏃や包丁などの古代日本の日常品に不可欠なる銘石「サヌカイト」の産地として広く輸出
弥生時代には巨大集落・古墳時代には全国の大半を占める独自の古墳「積石塚古墳」が多数築かれ、白鳳・飛鳥時代には多くの寺院が建造されたなど、瀬戸内海の航路の重要拠点として高い文化レベルを持っていた国
（大和朝廷の法を司る明法道の役職の3割超を讃岐の国人が占めていた）
