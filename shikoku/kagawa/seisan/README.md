弘法大師（空海）生誕の地とされる「第75番 善通寺」と5つの聖なる山「五岳山」や、四国八十八ヶ所霊場の最高峰「第66番 雲辺寺」・日本三大霊場のひとつ「弥谷山」などがある四国巡礼の核心部

善通寺周辺には、弥生時代の巨大集落跡・古墳時代に築かれた有力な王たちの古墳（有岡古墳群）、日本に仏教が伝来した飛鳥・白鳳時代（6世紀末〜7世紀）に建立された寺院・廃寺が密集する
* 全国的にも珍しい石だけを積み上げて造った「積石塚」の代表格である「野田院古墳（のたいんこふん）」が大麻山中腹に残るほか、王墓山古墳・宮が尾古墳などが点在

五岳山（火上山・中山・我拝師山・筆ノ山・香色山）の全山縦走の総距離は約9.5km〜10km、所要時間は約5時間〜6時間が目安
* 第71番 弥谷寺の南方にある登山口 - 火上山（ひかみざん、409m）山頂
* 火上山 - 中山（なかやま、439m）へ登り返し、最高峰「我拝師山（がはいしざん、481m）」山頂
* 我拝師山から標高差約300mを降ったのち、筆ノ山（ふでのやま、296m）への道は、体力・膝へのダメージが最も大きい区間
* 筆ノ山 - 香色山は緩やかな散歩道が整備され、第75番 善通寺へ通じる
