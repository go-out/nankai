四国地方最大の平野「讃岐平野（さぬきへいや）」の西部にあたる「三豊平野」に位置する観音寺市と三豊市からなる、香川県（讃岐）の西部地域

西讃地域の中心都市である観音寺市（かんおんじし）は、古来より霊峰として崇められる「琴弾山（ことひきやま）」や、島四国の一部をなす「伊吹島（いぶきじま）」などで知られる観光都市

伊吹島は、良質なイリコの生産が盛んで「イリコの島」として有名（漁期の6月から9月、島は活気にあふれる）
荒神社・西の堂 初夏（6月）に、かがり火のもと、夜神楽が奉納される（島四国の最後にお参りする寺院）
