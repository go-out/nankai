素麺、醤油、佃煮、胡麻油、オリーブなどの生産が盛んであり、いずれも日本有数の生産地
特にオリーブは国内栽培の発祥地として広く知られる

船でしか渡れない離島としては日本国内で最多の人口を有する島（別名は大野手比売（おおぬてひめ））
「天然の博物館」と呼ばれるほど生物の種類に富んでいる、船でしか渡れない離島としては日本国内で最多の人口を有する

大野手比売（おほのてひめ／おおのてひめ） - 小豆島（あずきじま、しょうどしま）

神名は、早苗取る早少女の意、黍・小豆・稲と禾穀に関係する名ではないかとする説がある
島内最高峰の星ヶ城山の西峰・東峰に鎮座する阿豆枳島神社は、江戸後期に再興された神社であるが、西峰に島玉神が祭られているされる
