古事記に見る神代の呼称は、猛々しい・勇猛の意とする説がある「建日方別（たけひかたわけ）」
（イザナギとイザナミが大八島国に次いで産んだ「六島」の初めの島）

かつては吉備国および備前国児島郡にあった島嶼だったが、江戸時代中期頃の新田干拓によって人工的に本土と繋がった陸続きの半島
* 島嶼であった地域は、現在の岡山県倉敷市南西部から岡山市南区南部、および玉野市に至る
* 周辺に点在する手つかずの自然と静かなビーチが残る離島へ、「下津井港」または「宇野港」から渡船（チャーター船）が運航

南西部（児島・下津井エリア）は、国産ジーンズ発祥の地
児島半島の東南部・玉野市（宇野・渋川エリア）は、直島などのアートの島々への玄関口となる港町
島（児島半島）と本州の間にあった海にあたる地、世界初の人造淡水湖「児島湖（こじまこ）」
