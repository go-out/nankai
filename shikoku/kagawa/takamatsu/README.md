四国地方最大の平野「讃岐平野（さぬきへいや）」に広がる四国地方最大の経済地区、国や企業の出先機関の多くが集積する「支店経済都市」

JR高松駅・高松港・高松空港などが揃う四国の玄関口としての利便性と、四国巡礼の最後の山岳霊場「屋島・八栗山」・結願（けちがん=全札所の巡礼達成）の地への山道などの豊かな自然と歴史が調和するエリア

四国八十八箇所のうち第83 ~ 87番札所までの6カ寺は、ローカル鉄道「ことでん（高松琴平電気鉄道）」の3つの路線（琴平線・長尾線・志度線）で結ばれる
* 琴平線は讃岐国一宮「田村神社」が隣接する「第83番 一宮寺」を経由し、金刀比羅宮（空海信仰の中心地「五岳山」方面）へ通じる
* 長尾線・志度線の終着駅近くには「第86番 志度寺（しどじ）」「第87番 長尾寺（ながおじ）」がある

（ことでん全線（琴平線・長尾線・志度線）が乗り降り自由となる「ことでん1日フリーきっぷ」、ことでん全線に加えてJR四国の特定区間（高松〜多度津〜琴平など）も乗り放題になる「ことでん・JRくるり〜んきっぷ」がお得）
