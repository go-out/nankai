讃岐平野の真ん中そびえる、讃岐国の国魂神が宿るとされる霊峰「飯野山」（別名「讃岐富士」）が立地する香川県の中部地域

瀬戸大橋の四国側玄関口（飯野山は瀬戸大橋の正面）にあたり、高松市に次ぐ香川県第二の都市「丸亀市」を中心に都市圏が形成されている
* 丸亀市から「金刀比羅宮」まで参道「丸亀街道・多度津街道」が通り、古くから金毘羅参りで賑わった地域
* 丸亀港から、塩飽諸島（牛島 - 本島・広島 - 手島 - 小手島）へフェリーが運航

高松エリアとの境には瀬戸内海に張り出した山塊「五色台（ごしきだい）」がある
