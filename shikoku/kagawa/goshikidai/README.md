弘法大師（空海）が金剛界曼荼羅の五智如来にちなんで名付けたとされる5つの峰（青峰、紅峰、黄峰、白峰、黒峰）からなる山岳霊場

五色台の山域にある80番國分寺・81番白峯寺・82番根香寺の3ヶ寺を結ぶ遍路道の一部は、国の史跡・歴史の道百選に指定されている

* 紅峰（こうみね、245m） - JR国分駅から白峯寺へ登る道中に左前方に望むことができる、赤みを帯びた岩肌と美しい円錐形（おむすび型）が特徴の峰（五色台の西端）
* 白峰（しらみね、374m） - 第81番札所 白峯寺の所在地、悲劇の帝・崇徳上皇の霊が眠る神聖な場所
（JR国分駅から国分寺を経由して白峯寺まで 約7km 約2時間30分）

* 黒峰（くろみね、375m） - 白峯寺から根香寺への道中（白峰と青峰の間）、黒峰の南側山腹をなぞるように進む
* 青峰（あおみね、436m） - 第82番札所 根香寺の所在地、青峰の原生林を国指定史跡「根香寺道」が通る
（白峯寺から五色台の最高地点付近（標高約460m）を経由して根香寺まで 約4.6km 約2時間）

* 黄峰（きみね、338m） - 五色台の東側、根香寺からJR鬼無駅へ下る道中の南東側に位置する
（根香寺からJR鬼無駅まで 約4.0km 約1時間30分）

（全行程の歩行時間は約6時間、総距離は約15km〜16km）
