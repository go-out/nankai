県面積の84％を森林が占める日本一の森林県（住地面積割合は16%で全国最小値）である高知県随一の平地であり中心都市
（高知県の総人口の約半分が集中する高知市は、四国内では愛媛県松山市・香川県高松市に次いで3番目の人口を有する）

太平洋に面する海沿いには土佐湾が広がり、飛鳥時代から名産とされたカツオの一本釣りが行われる（そうだがつお類の漁獲量日本国内1位）

* 四国山地から平地が開ける高知県の空・陸の玄関口「南国市（なんこくし）」は、古代には律令国家のもとで国衙が比江（ひえ）に置かれ、奈良時代には土佐国府があった土佐の中心地・政治の中心として栄えた地域
* 南国市の東北に接し、徳島県の山地との境に位置する「香美市（かみし）」は、高知県で唯一海に面していない市で、面積の約95%を自然豊かな山林が占める、陰陽道や古神道の1つといわれる「いざなぎ流」が伝わる地域
* 南国市の東南に接し、土佐湾の一部をなす海岸が広がる「香南市（こうなんし）」は、「手結のつんつく踊り」「手結盆踊り」などの伝統的な民俗芸能が残る港町
