高縄半島（たかなわはんとう）
JR予讃線はこの半島をほぼ海岸沿いに走っている
最北端である「大角鼻（おおすみはな）」にはキャンプ場くじら広場・大角海浜公園がある
中央部の山塊「高縄山地」は、豊かな自然が多く残されており、四国百名山に選ばれる「高縄山」「東三方ヶ森」などがある


今治市のうち、四国本土の高縄半島北東部・旧今治市を中心とした「陸地部」は、造船業で日本一の規模を誇る「今治造船」・国内の生産量の5割を占める日本一のタオル「今治タオル」の生産地として知られる、愛媛県・四国地方を代表する工業都市のひとつ
その他、調味料メーカー「日本食研」、「伯方の塩」を製造する伯方塩業などの本社・製造工場がある
温泉療法医がすすめる名湯百選に選ばれている「湯ノ浦温泉」

（陸地部に対して、芸予諸島の一部にあたる「伯方島・大島・大三島」を中心とした市域は「島嶼部」と呼ばれる）

古くは瀬戸内海の海上交通の要所だったが、「瀬戸大橋」や「しまなみ海道・とびしま海道」の開通などの影響により規模が縮小（現在は、西条市の「東予港」と「大阪南港」を結ぶ夜行フェリーが関西と四国を結ぶ唯一の航路）

西日本最高峰石鎚山の麓に位置する「西条市（さいじょうし）」は、雪解け水による豊富で良質な地下資源から「水の都」と称され、「うちぬき」と呼ばれる自噴水（地下水）は、名水百選・水の郷百選に選ばれている

太古より人が住んでいた地で、小松町明穂南方段丘の上に広さ6,000mにも及ぶ広大な旧石器時代の遺跡群・八堂山山頂付近からは弥生時代の高地性集落などが発見されて、船屋・天神山・氷見・小松・丹原と市内各地には古墳が存在する

典型的な瀬戸内海式気候で四季を通じて晴れの日が多く、降水量は少なめ

* 西条祭り（石岡神社例大祭・伊曾乃神社例大祭・飯積神社例大祭）
* 王至森寺の金木犀（キンモクセイ、国の天然記念物、かおり風景100選）
* 石鎚神社：石鎚山総本宮
* 保国寺：四国最古の庭園（名勝）
* 禎瑞の芝桜と石鎚山
* 禎祥寺 観音堂　藤
