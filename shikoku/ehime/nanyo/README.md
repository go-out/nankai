東西方向に四国山地が走り、支脈も多く、西方は山地がそのまま宇和海に接しリアス式海岸を形成（大洲盆地など一部を除き、平野には恵まれていない）
温暖な気候に恵まれたリアス式海岸は、生産量日本一を誇るマダイやシマアジ・真珠などが養殖される日本屈指の農林漁業拠点

かつては山を越さないと隣町に出ることができなかったため、各地に独自の文化が起こり、伝統文化として継承されている

圏域は大きく、八幡浜・大洲圏域と宇和島圏域に二分される

オレンジライナーえひめ号（大阪線） - 大阪行き（伊予鉄バス・阪急バス）
ウワジマエクスプレス（大阪・神戸 - 宇和島線） - 大阪・神戸行き（宇和島自動車・阪神バス）

八幡浜・大洲圏（八幡浜市 大洲市 西予市 内子町 伊方町）

盆地型で、霧が発生しやすい。肱川河口（長浜）では、肱川あらしという現象が観察される

八幡浜は、愛媛県の西端にある佐田岬半島の付け根に位置する、古くは九州や関西地方との海上交易が盛んで「伊予の大阪」と謳われた
水産物や練り物などを多用した独自の「ちゃんぽん」がローカル食
