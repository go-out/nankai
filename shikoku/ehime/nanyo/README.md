四国山地（千数百メートル級の急峻な山々）が東西方向に走り、かつては山を越さないと隣町に出ることができなかった「陸の孤島」と呼ばれるほどの交通の難所
現在は、JR予讃線・松山自動車道（高速道路）、宿毛方面や九州へと結ぶフェリーや路線バスが整備され、限られた平地や海岸線、トンネルを縫うように交通網が形成されている
* オレンジライナーえひめ号（大阪線） - 大阪行き（伊予鉄バス・阪急バス）
* ウワジマエクスプレス（大阪・神戸 - 宇和島線） - 大阪・神戸行き（宇和島自動車・阪神バス）

鉄道が通っていない愛南町（南宇和）や、鬼北・野村などの山間部にある個々の集落では、各自治体が運営するコミュニティバス（町営・市営）・デマンド交通のみが公共の移動手段

地理的障壁のより、わずか数十キロしか離れていない地域間でも全く異なる独自の文化・信仰・食・生活様式が起こり、現代まで大切に語り継がれる
* 牛鬼（宇和島市・愛南町） - 南予を代表する魔除けの神獣
* 鹿踊（宇和島市・西予市） - 仙台の「八鹿」に対し、宇和島では主に「五ツ鹿」や「七ツ鹿」として、切なくも美しい衣装をまとった踊り子が舞う
* いもたき（大洲市） - 肱川の河原に大鍋を囲み、里芋、鶏肉、こんにゃくなどを煮込んで食べる秋の風物詩
* *水産物や練り物などを多用した独自の「ちゃんぽん」がローカル食
