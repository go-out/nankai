江戸時代から明治時代にかけて木蝋（もくろう）の生産や大洲和紙などの伝統産業で莫大な富を築きました。現在も、大洲市の「伊予の小京都」と呼ばれる城下町や、内子町の白壁の町並み、さらにはこの地域特有の「屋根付き橋」など、往時の豊かな歴史文化がそのまま残されています。

大洲城の城下町や内子の製蝋（木蝋）で栄えたレトロな街道の文化が今も色濃く残る地域「大洲・内子地区（肱川流域）」

1. 喜多郡内子町（白壁と伝統工芸の街）
江戸〜明治期の面影がそのまま残る、手仕事と木蝋の街です。
• 八日市・護国地区の町並み： 約600メートルにわたって、浅黄色の漆喰壁や海鼠（なまこ）壁の豪商の邸宅が軒を連ねる重要伝統的建造物群保存地区です。
• 内子座： 大正5年に建てられた本格的な芝居小屋です。※現在は令和の保存修理工事に伴い長期休館中ですが、裏手の楽屋で見学や展示を楽しめます。
• 伝統の技： 国内でも希少な国内産の和蝋燭を作る「大森和蝋燭屋」や、100年以上続く「天神産紙工場」での大洲和紙漉き体験が人気です。

2. 大洲市（肱川の清流と城下町）
「伊予の小京都」と呼ばれ、中心部を流れる清流・肱川（ひじかわ）沿いに風情ある景色が広がります。
• 大洲城： 日本でも数少ない、当時の工法を忠実に守って木造復元された天守が美しいお城です。
• 臥龍山荘（がりゅうさんそう）： 肱川の最も美しい渓谷美を望む崖沿いに建てられた、意匠を凝らした数寄屋造りの名建築です。

• 大洲名物「とんくりまぶし」： 大洲特産の「栗」と豚肉を甘辛く炒め、ご飯にのせたご当地丼。最後はお出汁でお茶漬けにして楽しめます。
• 南予の「鯛めし」： 新鮮な鯛の刺身を、特製のタレと生卵、薬味に絡めて熱々のご飯にかけて食べる郷土料理です。内子駅近くの「りんすけ」などで味わえます。
