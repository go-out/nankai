日本三古湯の一つ「道後温泉」で知られる、太古から絶え間なく水（湯）が湧き出ずる特別な地
（伊予神社（伊予市）には、伊予国において貴重な水源だった湧水跡が残る）

* 古事記に見る神代の四国の呼称が「伊予之二名島（いよのふたなのしま）」とあることから、古代の四国で突出した勢力（文化圏）がこの地にあったと推測される
* 中世までは芸予諸島に位置する下島（大崎下島）・豊島、明治維新直前までは高知県宿毛市の一部（沖の島町母島・沖の島町鵜来島）までを国域に含んでいた
