四国の北西部「伊予国」は、古代より水の湧き出ずる特別な地だったとされる
中世までは芸予諸島に位置する下島（大崎下島）と豊島、明治維新直前までは高知県宿毛市の一部（沖の島町母島・沖の島町鵜来島）を区域に含んでいた

イザナミとイザナギの子で、ニニギの妻となる二柱の女神「木花之佐久夜毘売（このはなのさくやびめ）」・「石長比売（いわながひめ）」を子に持つ「大山積神（おおやまづみのかみ）」は、芸予諸島の大三島に鎮座する「大山祇神社（おおやまづみじんじゃ）」ほか、全国にある三島・大山祇信仰の神社に祀られる

四国最大の人口を抱える都市であった、愛媛県松山市（夏目漱石の小説「坊っちゃん」の舞台）
