日本総鎮守とも称される大山祇神社の寺社領だった「三島七島（生奈島（生名島）・岩城島・大三島・大下島・岡村島・御手洗島（大崎下島）・豊島）」、戦国時代に活動した日本最大の海賊「村上海賊」の本拠地だった島々（因島・能島・来島）などを有する大小数百の島からなる多島海

広島県（安芸国・芸州）と愛媛県（伊予国）にまたがり、島々には海峡横断長距離自転車道「しまなみ海道」と「安芸灘とびしま海道」が整備されている

* 安芸（安藝・阿岐、あき）は、現在の広島県広島市・呉市・竹原市・大竹市・廿日市市・安芸高田市・江田島市・安芸郡・豊田郡の全域および三原市の一部
* 伊予（いよ）は、現在の愛媛県にあたる（伝統的には「伊豫」の名称であり、「伊予」「伊与」の表記も用いられた）
