広島県（安芸国・芸州）と愛媛県（伊予国）の間に位置する「世界で最も素晴らしい自転車道の1つ」が整備されている諸島

日本総鎮守とも称される大山祇神社の寺社領だった「三島七島（生奈島（生名島）・岩城島・大三島・大下島・岡村島・御手洗島（大崎下島）・豊島）」や、戦国時代に活動した日本最大の海賊「村上海賊」の本拠地だった島々（因島・能島・来島）など、多くの観光資源を有する大小数百の島からなる多島海

大島には島四国と呼ばれる巡礼の道があり、毎年4月の第3土曜日を初日とする3日間は「へんろ市」が開催される

* この3日間だけは各札所で島人によるお接待が行われる
* へんろ市では高龍寺のお接待のうどんが大人気。
