吉野川右岸（南側）地域に位置する、阿波国を開拓した天富命（阿波忌部氏の祖神）が穀・麻種を植えたことに由来し、古くは「麻植郡（おえ）」と呼ばれた現在の吉野川市と、現在の美馬市にあたる「美馬郡（みま）」
古くは「阿波郡（あわ」と呼ばれた、現在の阿波市の大部分・吉野川市の一部にあたる吉野川左岸（北側）地域


"市場町（いちばちょう）にある日本最大の川中島「善入寺島」は、夏には一面のひまわり畑が広がる絶景スポット",
"阿波町（あわ）は、吉野川の肥沃な土壌を活かしたレタスなどの野菜栽培（阿波ベジ）など、広大な平地を活かした農業が非常に盛ん",

* 日本書紀では、阿波国を開拓・穀麻を植えて紡績の業を創始した「天日鷲神（アメノヒワシノカミ）」が阿波忌部の祖神とされる
* 古語拾遺では、神武東征において忌部氏を率いて、木（紀伊）国の材木を採取し畝傍山の麓に橿原宮を造営した「天富命（あめのとみのみこと）」が、肥沃な土地を求めて阿波国を耕し、穀・麻種を植えたという

阿波忌部の末裔とされる三木家は、天皇即位の大嘗祭に際して調進される「麁服（あらたえ）」の元となる麻を育てている
（同音の安房国（現在の千葉県南部）は、阿波国から移り住んだ人々が開拓したことから名付けられたとする説がある）
