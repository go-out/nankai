徳島県の三好市山城町で冠山（愛媛県新居浜市）に源を発する最長の支流「銅山川」と合流し、徳島県を東西に流れ、紀伊水道（瀬戸内海）に注ぐ、「吉野川（よしのがわ）」の河口に近い流域

川に沿って徳島県の東西（徳島駅〜阿波池田駅間）を結ぶ、よしの川ブルーラインの愛称を持つJR四国の路線「徳島線」が、1時間に1〜2本運行
* 1日に数本のみ特急列車「剣山」が運行（土休日や夏・冬休みなどには「ゆうゆうアンパンマンカー」が連結される）
___

吉野川市は、阿波国を開拓した天富命（阿波忌部氏の祖神）が穀・麻種を植えたことに由来し、古くは「麻植郡（おえぐん）」という名だった地域にあたる

* 日本書紀では、阿波国を開拓・穀麻を植えて紡績の業を創始した「天日鷲神（アメノヒワシノカミ）」が阿波忌部の祖神とされる
* 古語拾遺では、神武東征において忌部氏を率いて、木（紀伊）国の材木を採取し畝傍山の麓に橿原宮を造営した「天富命（あめのとみのみこと）」が、肥沃な土地を求めて阿波国を耕し、穀・麻種を植えたという

阿波忌部の末裔とされる三木家は、天皇即位の大嘗祭に際して調進される「麁服（あらたえ）」の元となる麻を育てている
（同音の安房国（現在の千葉県南部）は、阿波国から移り住んだ人々が開拓したことから名付けられたとする説がある）
