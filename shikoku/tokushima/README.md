古来より近畿地方との繋がりが深く、現在でも南海フェリー（徳島港 - 和歌山港）で近畿地方と結ばれる、大阪・和歌山と結びつきが深い四国の玄関口

* 鮎喰川左岸・気延山東側山麓に広がる扇状地と沖積地域には、西日本最大級の縄縄文時代から中世にかけての複合遺跡「矢野遺跡」があり、古代日本において重要な地だったと推測される
* そのほか周辺には、四国八十八箇所第十三番から十七番の札所（寺院）が点在する
