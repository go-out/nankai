イザナギとイザナミが淡路島に次いで創造した大八島国の二島目
一つの体に四つの顔がある、「伊」と「予（豫）」の二つの名を持つ島

1. 愛比売（えひめ） - 伊予国
2. 飯依比古（いいよりひこ） - 讃岐国
3. 大宜都比売（おおげつひめのかみ） - 粟国（阿波国）
4. 建依別（たけよりわけ） - 土佐国

***

二つの名は、古代の四国で特に勢力が大きかった2つの異なる風土・勢力（文化圏）を表すと解釈されている

* 「伊（い）」は「いづ（出る・いずる）」に通じる太陽が昇る側（伊予国、瀬戸内側の文化圏）
* 「予（よ）」は「いよ（いよいよ・弥）」に通じる広く広がる海（土佐国、太平洋側の文化圏）
（讃岐と阿波はのちに分かれた、あるいはこの2大勢力に内包されていたと考えられている）
