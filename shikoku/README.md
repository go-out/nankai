イザナギとイザナミが淡路島に次いで創造した大八島国の二島目
「伊」と「予（豫）」の二つの名を持つ一つの体に四つの顔がある島

1. 愛比売（えひめ） - 伊予国
神名は、「うるわしい女性」や「美しい女性」を意味するとされる「愛媛」の語源
古来の表記は「伊豫」（「伊与」の表記も用いられたという）

2. 飯依比古（いいよりひこ） - 讃岐国
神名は、飯の霊が依り憑く男性とする説がある（現在の香川県のほぼ全域）
古来の表記は「讃伎」「賛支」（四国内の他の国よりも緯が狭いために「狭緯（さぬき）」とも称された）

3. 大宜都比売（おおげつひめのかみ） - 粟国（阿波国）
国産みの後に、イザナギ・イザナミが行った「神産み」の際に、五穀の起源に関わる女神として現れる「大宜都比売神（オオゲツヒメ）」と同一神とされる
また、高天原を追放された須佐之男命（スサノオ）に料理を振る舞う（後にスサノオに殺され、たくさんの穀物を生む）神としても登場する

4. 建依別（たけよりわけ） - 土佐国
神名は、勇猛な霊が依り憑く男性とする説がある
古来の表記は「土左」「都佐」（現在の高知県のほぼ全域）

***

島内には、お遍路（へんろ）と呼ばれる修行の道で通じる88の仏教寺院「四国八十八箇所」が点在し、その間にある急峻な山や深き谷・仏堂を残らず巡る488里の道を巡礼する伝統「四国巡礼」は、文化庁が認定する「日本遺産」に指定されている

（古代より、海辺の道を廻ることを辺地（へんち・へち）といい、空海が巡った修行の道が起源となり、空海の入定後（平安時代以降）に修行僧らがその跡を辿った末、室町時代頃に現在の遍路が定められたとみられる）
