熊野古道の中辺路（なかへち）と大辺路（海辺の道・海路）の分岐点にあたる田辺市街（紀伊田辺・朝来駅周辺）は、「口熊野」と称される熊野三山への西側の入り口にあたる地域

中辺路のうち「熊野本宮大社」までのほとんどは田辺市（和歌山市に次いで和歌山県内第2位の人口、紀伊南部の経済・産業の中心地）に位置する
（観光地として一般的に知られる「熊野古道」は、中辺路の当区間を指す）

道中には「九十九王子（くじゅうくおうじ）」と総称される神社が点在し、中辺路と並行するように、田辺（白浜）・本宮大社・新宮を結ぶバスが複数運行する
