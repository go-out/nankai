高野山全域が「金剛峯寺（こんごうぶじ）」の境内地
100か寺以上の寺院が密集する日本では他に例を見ない宗教都市

京都の東寺と共に、真言宗の宗祖である空海（弘法大師）が修禅の道場として開創（真言密教の聖地、また、弘法大師入定信仰の山）
1872年（明治5年）までは女人禁制であったため、高野七口とよばれる高野山への入り口7つそれぞれに、女性のための籠もり堂（参籠所）として女人堂が置かれた

***

空海は、最澄（天台宗の開祖）と並び、平安仏教を開いた僧（著作家、書道家であり社会事業家）
宝亀5年（774年）讃岐国屏風浦（香川県善通寺市）に生まれ、弘仁7年（816年）に嵯峨天皇から高野山の地を賜った
