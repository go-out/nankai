「山がちで木が多く自然豊か」なことから、古くは「木」の国と呼ばれ、それが転じて「紀伊」の国の二字になったとされる、日本神話にも言及が見られる神聖な地

紀伊半島（和歌山県の全域・奈良県南部の吉野地域・三重県松阪市以南の南勢・志摩・東紀州地域）の中央部に連なる「紀伊山地」は、太古から自然を神格化して崇める信仰が盛んな聖域

仏教伝来以後は日本の土着信仰と仏教とが癒合した修験道として吉野・高野山が成立
また、紀伊半島を浄土とみなす熊野信仰の霊場「熊野三山」としても発展

3つの霊場（吉野・大峰、熊野三山、高野山）と参詣道は、2004年（平成16年）7月7日に世界遺産（文化遺産）に登録されている

* 夏から秋にかけては台風が多く襲来する、日本有数の台風銀座
* 高野山など中部の山地では、冬に雪が降ることも多い
