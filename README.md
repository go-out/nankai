「淡路島」は、イザナギとイザナミが創造した日本の国土「大八島国（おおやしまのくに）」の一島目、国産み神話の始まりの地
* 淡路島の南に浮かぶ「沼島（ぬしま）」は、イザナギとイザナミが国産みを行った「オノゴロ島」とも伝わる

「四国」は、大八島国の二島目（北海道・本州・九州とともに日本の主要4島の一つ）
島内には、お遍路（へんろ）と呼ばれる修行の道で通じる88の仏教寺院「四国八十八箇所」が点在し、その間にある急峻な山や深き谷・仏堂を残らず巡る488里の道を巡礼する伝統「四国巡礼」は、文化庁が認定する「日本遺産」に指定されている
* 周辺には、イザナギとイザナミが大八島国に次いで産んだ「六島」のうち「児島半島・小豆島」などの島々があり、四国本土と付随する島々を含めて「四国地方（しこくちほう）」と総称される

「紀伊半島」に位置する紀伊山地（和歌山県のほぼ全域、奈良県・三重県の南部）は、日本神話において、常世の国への入口・初代天皇を大和へ導いた八咫烏の聖域として登場する神聖な地
* 紀ノ川流域は奈良盆地と太平洋を結ぶ重要な交通路であり、海洋民との交流や外交ルートとして機能していた
* 奈良の吉野山と和歌山の熊野三山を結ぶ修験道「大峯奥駈道」や、伊勢神宮・熊野三山・高野山を結ぶ参詣道などは、世界遺産「紀伊山地の霊場と参詣道」に指定されている
