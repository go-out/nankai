熊野三山（くまのさんざん）は、日本全国に約3千社ある熊野神社・十二所神社の総本社である、3つの神社「熊野本宮大社」「熊野速玉大社」「熊野那智大社」の総称

仏教的要素が強く、三社を結ぶ参詣道や吉野山・金剛山へと繋がる道は、ユネスコの世界遺産「紀伊山地の霊場と参詣道」の一部
（当初は別個の展開をたどり、本宮は崇神天皇代、速玉は景行天皇代（『扶桑略記』）、那智は孝昭天皇代に裸行（裸形とも）が開基）

熊野本宮大社：全国にある熊野神社の総本山で、かつての境内地である大斎原（おおゆのはら）には日本一の大鳥居がそびえます。
熊野速玉大社：熊野川の河口付近に位置し、鮮やかな朱塗りの社殿と樹齢約千年のナギの大樹が特徴です。
熊野那智大社：那智山の中腹にあり、隣接する青岸渡寺や日本一の落差を誇る「那智の滝（飛瀧神社）」とともに神仏習合の姿を今に伝えています。

過去・現在・未来の救済：速玉大社が前世（過去）の罪を浄め、那智大社が現世（現在）の縁を結び、本宮大社が来世（未来）を救済するといわれ、三山を巡ることで安寧を得ると信じられてきました。

熊野古道　Kumano Kodo Pilgrimage Route

本宮大社（中辺路）
紀伊田辺駅（または朝来駅）周辺から熊野本宮大社（本宮大社）へ通じる参詣道・熊野古道の一部
観光地として一般的に知られる「熊野古道」は、中辺路の当区間を指す

中辺路（本宮大社 - 那智大社）
那智・妙法の山々を登る熊野古道随一の景観美、中辺路の最難関「大雲取越・小雲取越」
熊野那智大社・那智山青岸渡寺と熊野本宮大社（本宮大社）を結ぶ、雲をつかむがごとき険しい旅路
距離 約14.5km、標準歩行時間 約5時間（歩行時間に休憩時間は含まない）

中辺路（那智大社 - 速玉大社）
那智川に沿って熊野那智大社と那智の浜を結ぶ道／那智の浜から熊野速玉大社へ通じる海沿いの道
那智駅 - 熊野那智大社の所要時間は約4時間
熊野速玉大社 - 那智駅の所要時間は約6時間
