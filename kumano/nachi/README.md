大雲取山（966m）・烏帽子山（909m）・光ヶ峯（686m）・妙法山（749m）などの山々からなる「那智山（なちさん）」に位置する、吉野へ続く修験道「大峯奥駈道」の第2の靡（なびき）

創成の詳細は不明、熊野坐神社（本宮）・熊野速玉大社（新宮）の二社とは異なり、山中の那智滝を神聖視する原始信仰が起源（当初は那智滝の正面にある現・飛瀧神社の地に社殿があった）
一説には、那智山の奥にある妙法山に登るための禊祓の地だった那智滝が聖地化し、夫須美神が勧請されて当社が滝本で創建されたともいう

那智山には禰宜や神主などの神職は存在せず、隣接する如意輪堂（現・青岸渡寺）と神仏習合して一体化する霊場となっていた
明治時代になり神仏習合が廃され行者堂が取り壊されたが、2023年（令和5年）10月に青岸渡寺の境内に再建
