奈良県と三重県に跨る国内有数の多雨地帯「大台ヶ原」を源に、伊勢神宮の神域の西側を流れて伊勢湾に注ぐ、古くは「神の川」と呼ばれた「宮川」の上流域
数々の絶壁・名瀑などの神秘的な大自然が残る名渓「大杉谷」

* 豊受大神宮（神宮外宮）の禊川（みそぎかわ）であったことから、かつては「豊宮川（とよみやがわ）」と呼ばれたが、「豊」の字を略して「宮川（みやかわ）」になったとされる
* 古来より度重なる洪水を引き起こす「暴れ川」と恐れられ、架けられた橋は幾度も流されたと記録が残る（明治期までは増水に耐えられる堅固な橋はなく、渡河手段は渡し船のみだった）

「大杉谷（おおすぎだに）」の名は、木を司る神「久久能智神（ククノチ）」を祭る樹齢1200年以上と伝わる巨大な杉「大杉谷の大スギ（大杉）」に由来する
大杉谷の豊かな森林は、神宮の社殿に使用される御用材（ヒノキ）の伐採地「御杣山（みそまやま）」として、古くから神宮と深い関わりを持つ（安土桃山時代から江戸時代にかけて計7回、式年遷宮の用材を産出）

* 大杉谷峡谷を含む大台ヶ原全域には、シダ植物と種子植物合わせて約900種（日本の植物約4000種のうちの1/4にあたる数）ほどの植物が生育
* 雨が多い気候が織り成す独自の美しい自然環境や動植物の生態系は、国の特別天然記念物・国際連合教育科学文化機関（ユネスコエコパーク）の生物圏保護区に登録されている
