「伊邪那岐（イザナギ）・伊邪那美（イザナミ）」は、別天津神たちに日本を完成させるよう命じられ、天と地の間の虚空にある浮き橋「天浮橋（あめのうきはし）」に立ち、「天沼矛（あめのぬぼこ）」で渾沌とした「地（大海）」をかき混ぜ、日本の国土の始まり「オノゴロ島」を創成

* 古事記では「淤能碁呂島（おのごろじま）」、日本書紀では「磤馭慮島（おのころじま、初字は「磤」）」
* また、「自（おの）ずから凝り固まってできた島」を意味し、「自凝島」とも表記される
（近世以降のほとんどは、淡路島の南にある「沼島（ぬしま）」説が定説）

___

オノゴロ島に降り立ち、イザナギ・イザナミが最初に産んだ「ヒルコ（水蛭子、蛭子神、蛭子命）」は不具の子だったため、葦船（あしぶね）に乗せて流してしまう
ヒルコが流れ着いたという伝説は日本各地にあり、日本沿岸の地域ではえびす神として信仰するところが多い（ヒルコとえびす（恵比寿・戎）を同一視する説は室町時代からおこった新しい説）

***

ヒルコに次いで、産まれた「淡島（アワシマ）」も同じく不具の子だった
和歌山加太の淡嶋神社を総本社とする全国の淡島神社や淡路神社の祭神であるほか、「淡島」という島ならびに地名は日本各地に存在している
（記紀に、少彦名神が粟島（アワシマ・伯耆国粟島に比定）から常世の国へ渡ったとする記述があることから、加太淡島神社を始めとする多くの淡島神社の現在の祭神は、出雲の国造りをした少彦名神・大国主神とされている）

___

ヒルコ・アワシマに次いで生まれたのは、日本列島のうち最初に創造された島「淡路島」、淡道之穂之狭別島（あわじのほのさわけのしま）

弥生時代（紀元前4世紀半ば-紀元前2世紀半ば頃）の銅鐸「中川原銅鐸」「松帆銅鐸」や、1世紀頃の村の跡「五斗長垣内遺跡」が発見されていることから、淡路島には半島・大陸から当時の先端技術が伝来していたと考えられる
（また、古代の日本国家は、後に「淡路の海人（あま）」と呼ばれる海の民によって支えられたとも考察されている）
