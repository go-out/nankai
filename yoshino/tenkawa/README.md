修験道の開祖「役行者（えんの おづぬ）」が法華経八巻を埋納したという伝説から、仏経ヶ岳とも呼ばれる「八経ヶ岳（はっきょうがたけ、標高約1915m）」は、日帰り登山ができる百名山としても栄える近畿地方の最高峰
* 八経ヶ岳の山腹に自生するオオヤマレンゲ（7月上旬に花を咲かせる）・付近の原始林「仏経嶽原始林（ぶっきょうがたけげんしりん）」は、国の天然記念物に指定されている

八経ヶ岳の北方には、古代から霊峰として信仰された「弥山（みせん、標高約1895m）」・南方には明星ヶ岳（みょうじょうがたけ、標高約1894m）といった複数の峰が近接し、南方の山小屋「楊枝の宿（楊子宿避難小屋）」から、大峯山の女人結界門がある「阿弥陀森（小篠の宿）」までの間には、第44番から66番の靡（行場・霊場）がある大峯山系最大の行場

* 弥山の西方山麓には、弥山の鎮守「天河大辨財天社（天河神社）」、山頂には天河神社の奥之院「弥山弁財天社（弥山神社）」が鎮座する
* 弥山の山頂からは奈良時代の遺物が出土し、平安時代以降より修験道の行場として信仰されたと伝わる（古くは深山や御山と書かれ、仏教用語の須弥山から転じて弥山と呼ばれるようになった）

___

弥山・八経ヶ岳への登山道は、大峰山脈を南北に貫く大峯奥駈道の他、天川川合または坪内から栃尾辻を経るルート、行者還トンネルから入り大峯奥駈道に合流するルートなどがある

* 天川川合登山口までは、近鉄吉野線「下市口駅」から奈良交通バス「中庵住（なかいおずみ）行」または、「洞川温泉行」に乗車し「天川川合」下車
* 坪内登山口までは、奈良交通バス「中庵住行」に乗車し「天河大弁財天社」下車（1日3便）
