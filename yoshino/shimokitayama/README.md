大峯奥駈道の北部と南部を分ける聖なる結界の地「太古の辻（たいこのつじ）」を中心とする行場
（太古の辻から熊野本宮までの南側45km間は「胎蔵界（南奥駈道）」・北側は「金剛界」と呼ばれる）

巨岩と木々が美しい景色を織りなす「釈迦ヶ岳 - 大日岳」は、大峯山系随一の眺望・絶景と称される
* 大峯山系の霊的シンボルとも言える「大日岳（だいにちだけ）」は、修行以外の一般の立入は勧められない大変危険な急斜面の岩場・鎖場
* 奈良県十津川村と下北山村の境にある「釈迦ヶ岳（しゃかがたけ）」は、釈迦入滅の地と伝わる（地元には、仏教の開祖・お釈迦様の誕生日の四月八日に登拝する習慣が残る信仰の山）
* 釈迦ヶ岳の北方にある「仏生ヶ岳（ぶっしょうがたけ）」は、釈迦誕生の地とされる

___

南奥駈道には、誰もが安全に山を歩けるようにとボランティア団体「新宮山彦ぐるーぷ」によって維持管理されている3棟の山小屋「持経宿・平治宿、行仙宿」がある
* 宿泊利用は原則として予約制（連休中あるいは多人数利用の際は、予約必須）
* 宿泊費（維持管理費用）として、1泊1人2000以上を納付箱に納付

***

太古の辻から本道を東に分岐した先にある「前鬼（ぜんき）」は、平安中期ごろすでに開けていた村で、江戸時代までは「霊場の奥座敷」とも言われる修験道の一大拠点だった地域

（役行者に従った前鬼・後鬼の子孫と伝えられる五鬼熊（行者坊）・五鬼童（不動坊）・五鬼上（中之坊）・五鬼継（森本坊）・五鬼助（小仲坊）の五家がそれぞれ宿坊を営み、役行者の教えを祖述しつつ、汲水・採薪・食事の準備等を行ない山伏に給仕し、奥駈けの荒行を裏から支え入峯の先達をつとめたと伝わる）
