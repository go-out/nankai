大和の都から遠いという意味から「十津川（遠津川・遠都川）」と呼ばれた奈良県の最南部に位置する新宮川（熊野川）水系流域
* 農耕に適さない山間部にあるため、古来免租の地域としてその時々の権力者の支配を受けずに半ば独立した村落共同体として存在し続けた（周囲とは隔絶した地域のため、独特の文化・気風が残る地域）

中心部には、日本百名湯のひとつである「十津川温泉郷」と総称される三つの温泉（上湯温泉・湯泉地温泉・十津川温泉）があり、空海が開いた密教の聖地「高野山」と熊野を結ぶ参詣道・熊野古道のひとつ「小辺路（こへち）」が南北に通る

標高1000mを超える深い山中には、熊野本宮大社の奥之院とも言われる「玉置神社」が鎮座する霊峰「玉置山（たまきさん、標高約1076m）」があり、熊野と吉野を結ぶ山岳道「大峯奥駈道」が通る
