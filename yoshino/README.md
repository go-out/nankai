古来の自然信仰と渾然一体となった中国渡来の神仙思想や道教、仏教の修行のために、藤原京や平城京からこの地を訪れた僧侶（修験者）によって切り開かれたことに始まり、飛鳥時代の終わり頃の文武天皇の時期に役小角によって開山

修験者にとって最も神聖な縦走路とされる標高千数百メートル級の山々を縦走する約80kmの全行程を歩き通すには、4泊5日から1週間程度を要する（日本最古のロングトレイルとも呼ばれる）

修験者は、5月3日の戸開けから9月23日の戸閉めまでの間に、道中に設けられ「靡（なびき）」と呼ばれる75の行場（霊場）を巡る奥駈修行を行なう
* 75の靡は、熊野本宮大社の本宮証誠殿（1番）にはじまり、吉野川河岸の柳の宿（75番）に終わる（古くは宿と呼ばれ、120宿あったという）
* 山伏（修験者）が大峯で修行することを「峯（みね）入り」「入峯（にゅうぶ）」と言う
* 本宮から吉野に向かう道を「順峯（じゅんぷ）」、吉野から本宮に向かう道を「逆峯（ぎゃくふ）」と呼ぶ

（順峯は天台宗系の聖護院（本山派）が、逆峯は真言宗系の醍醐寺三宝院（当山派）がそれぞれ主導する）

大峯奥駈道の南北を分ける結界の地「太古の辻」より南部（南奥駈道）は、一切を包み込む慈悲の聖域「胎蔵界（たいぞうかい）」

* 熊野三山の中心「熊野本宮大社」からの入峰（順峯）は、周辺のキャンプ場に宿泊して早朝に出発し、熊野三山の奥の院を称する玉置神社がある「玉置山」まで約9時間（道中に山小屋などの宿泊施設はない）
* 玉置山から太古の辻までの山々には複数の宿泊施設（山小屋・宿坊）があり、弥山・八経ヶ岳（または、霊場の奥座敷とも言われる「前鬼」）までを2泊3日程度で奥駈する

***

太古の辻より北部は、南部の胎蔵界に対して、悟りの境地と仏の智慧を表現した「金剛界（こんごうかい）」にあたる
* 太古の辻（前鬼・深仙宿）周辺 - 大日岳・釈迦ヶ岳 - 弥山・八経ヶ岳（天川川合）の所要時間は2泊3日程度
* 前鬼から「大日岳・釈迦ヶ岳」・天川から「弥山・八経ヶ岳」は、1泊2日（または日帰り）で登山可能

弥山（八経ヶ岳）の北／吉野の南に位置する「金峰山（五番関から阿弥陀ヶ森まで）」は、宗教上の理由から現在も女人禁制が堅持されている聖域

* 吉野側（逆峯）の起点は、近鉄吉野線「六田（むだ）」駅（近鉄吉野線の終点「吉野」駅・吉野ロープウェイ「吉野山駅」からの入峰も一般的）
